Qubik Scanner Bêta gratuite

Ton modèle Roblox cache-t-il une backdoor ?

Dépose un fichier .rbxm, .rbxmx, .rbxl, .rbxlx ou .lua. L'analyse se fait entièrement dans ton navigateur : rien n'est envoyé sur Internet.

Ce que le scanner détecte

  • Modules externes cachés : require(123456), IDs encodés…
  • Code obfusqué : Luraph, IronBrew, MoonSec, texte encodé, lignes géantes
  • Exécution à distance : loadstring, getfenv, InsertService
  • Fuites de données : webhooks Discord, Pastebin, serveurs externes
  • Virus : scripts qui se recopient ou se cachent
  • Pièges : actions déclenchées seulement pour un joueur précis ou hors Studio

Un scan automatique ne remplace pas une relecture humaine. Un résultat « propre » réduit fortement le risque, mais ne le supprime pas complètement.
